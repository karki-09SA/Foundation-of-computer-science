# ST4015CMD Foundation of Computer Science

## Files

| File | Task |
|---|---|
| task1_encoding.py | Task 1 - Encoding formats (Base64, ASCII, URL, Hex) |
| task2_brute_force.py | Task 2 - Brute force seating solver |
| task2_heuristic.py | Task 2 - Heuristic seating solver |
| schema.sql | Task 3 - Create tables and insert data |
| queries.sql | Task 3 - SQL queries with expected outputs |

## How to Run Python Files

```bash
python task1_encoding.py
python task2_brute_force.py
python task2_heuristic.py
```

Requires Python 3. No extra libraries needed.

## How to Run SQL Files

Open MySQL Workbench or any SQL editor and run schema.sql first, then queries.sql.

```sql
SOURCE schema.sql;
SOURCE queries.sql;
```
